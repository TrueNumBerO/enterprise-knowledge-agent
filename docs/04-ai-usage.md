# 04 AI 辅助与贡献声明

## 真实使用范围
本项目由用户委托的 AI 项目经理组织实施，代码、合成资料、测试、文档主要由 AI 生成并通过工具执行验证。不能将这些材料宣称为候选人纯手工完成。

| 参与方 | 工作范围 | 验证职责 |
|---|---|---|
| 用户 | 提供题目、目录边界和协作要求，确认先交付本地/离线/真实接入入口 | 尚未记录用户亲自运行或改写代码 |
| 项目经理 agent | 题目拆分、接口合同、公开架构调研、分工、文档、集成评审 | 检查实际测试产物和实现一致性，复验可复制命令 |
| 开发 agent | 模型适配、动作循环、证据校验、CLI | 与独立测试 agent 交互修复缺陷 |
| 检索资料 agent | 文档检索/读取、合成制度、同义词、场景输入 | 原文替换、过期标注处理及检索质量检查 |
| 测试 agent | 独立 unittest、HTTP stub、场景评估脚本 | 执行测试并向开发反馈，生成实际 trace |

## 修改与验证的记录原则
不编造“个人贡献”或“亲自验证”。后续候选人应在提交前亲自阅读代码、运行测试，并补充自己的修改记录、理解与验证结果。当前实际机器执行结果以 `examples/evaluation.json` 及测试记录为准。

## 外部资料与工具
使用官方公开仓库和厂商 API 文档做架构调研，引用见 `07-architecture-research.md`。未复制框架源代码，运行时零第三方依赖。使用本机 Python 标准库、PowerShell 和多 agent 协作工具完成开发。未读取真实业务数据或提交密钥。

## 诚实性边界
- 离线模型的规则逻辑不等于真实 LLM 决策，不作为题目的真实模型效果证明。
- 本地 HTTP stub 验证协议与观察回传，不能代表厂商服务稳定性或模型能力。
- 未发布 GitHub 仓库，不伪造 URL 和远程 commit SHA。
- 本轮不声称达到生产级安全、企业级召回或任意文档自动冲突识别。
